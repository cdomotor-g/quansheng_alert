ALERT RX firmware installer

Installs the flood-warning telemetry receiver firmware onto a Quansheng UV-K5. It backs up your radio first, then does the rest itself — there is nothing to download, unzip or compile.

This browser can’t talk to the radio

Flashing needs Web Serial, which only Chrome, Edge and other Chromium browsers have, and only on a desktop or laptop (Windows, macOS, Linux or ChromeOS).

Open this same page in Chrome or Edge on a computer and you’re away.

1 Pick the firmware

Both builds are the same program. They differ only in which region’s station names are stored in the radio, because there is only room for about 6 KB of names. Addresses outside the list still decode — you just see the number instead of the name.

Use my own firmware file instead

For flashing a build you made yourself, or going back to stock Quansheng / egzumer firmware. Both .packed.bin and raw .bin files work; the file is checked before anything is sent to the radio.

2 Plug in and connect

You need the two-pin programming cable — the same one Baofeng radios use, with a 3.5 mm and a 2.5 mm plug at one end and USB at the other. The radio’s own USB-C socket will not do: it is wired to the charging circuit only, so no software can reach the radio through it. Check the box the radio came in — many kits include a programming cable as well as the charging one. Otherwise any “Kenwood 2-pin / K1 USB programming cable” works (about $10; prefer one that says CH340, as the cheap “PL2303” cables are often counterfeit chips that Windows refuses to drive). Got a USB–TTL adapter and a soldering iron? Build one instead.

  1. Plug the programming cable into the radio’s side socket (under the rubber flap) and into a USB port. Push the two plugs in firmly — a half-seated plug is the most common reason this fails.
  2. Switch the radio on normally (just turn the volume knob). Leave it on a normal channel screen.
  3. Press Connect and choose the cable from the list your browser shows. It is usually called USB-SERIAL CH340, USB Serial or Prolific.

The list is empty, or the radio isn’t answering
  • Nothing in the list: the cable’s driver isn’t installed. Most cables use a CH340 chip — install the CH340 driver, unplug and re-plug the cable, then try again.
  • Port appears but the radio doesn’t answer: push both plugs in harder, make sure the radio is switched on, and close any other program that might hold the port open (CHIRP, a serial terminal).
  • Some cables are wired for a different radio family. If yours has never worked with CHIRP either, that is the likely cause.

3 Back up your radio

This saves your radio’s EEPROM: the factory calibration, every channel, and all your settings. That is the part which is unique to your radio and can’t be downloaded from anywhere — so we take a copy before changing anything. It takes about ten seconds and doesn’t alter the radio.

Worth knowing: the firmware itself can’t be read out of the radio — the bootloader has no “read” command, so no tool can do it. That’s not a problem: firmware is replaceable in a minute from this page or from stock images, whereas your calibration is not. The backup below is the one that matters.

4 Install the firmware

Now put the radio into bootloader mode. Leave the cable plugged in the whole time — the radio can be switched off and on without the computer losing the connection.

  1. Switch the radio off.
  2. Hold the PTT button (the big one on the side) and, while holding it, switch the radio on with the volume knob.
  3. The torch LED at the top glows white and the screen stays blank. That’s bootloader mode. Let go of PTT.

Nothing here can permanently damage the radio. The bootloader lives in a separate part of the chip that is never written, so if a flash is interrupted the radio still starts in bootloader mode and you simply do it again.

✓ Done

Set it up, once

  1. Menu → Voice → English, so it reads the readings out.
  2. Menu → Sql: start at 0.0 and raise it in tenths until the static just goes quiet.
  3. Tune to 151.500 MHz, FM.
  4. Press F then 0 to open the ALERT receiver.

The full guide, including what every setting does and how to run the first on-air test, is in the project README.

Toolbox

What is my radio running?

Asks a radio that is switched on normally which firmware it has. Connect first (step 2).

Restore a backup onto the radio

Writes a previously saved EEPROM backup back into the radio: calibration, channels and settings. The radio must be switched on normally (not bootloader mode) and connected.

Only ever restore a backup taken from this radio. Another radio’s calibration will make yours transmit and receive off-frequency.

Backups and installs on this computer

This page keeps a copy of your last few backups in the browser, as a safety net in case the downloaded file goes missing. They never leave your machine.
